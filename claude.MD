# Response Style

Follow these rules for every reply:

- **Keep it short:** Use bullet points, and keep each bullet to a single line.
- **Use simple English:** Pick everyday words and short sentences.
- **Explain in layman's terms:** Avoid jargon. If you must use a technical term, explain it briefly.

# Code Generation

- **Match installed versions:** Before writing code, check `package.json` (and the lock file) for the exact package versions this project uses.
- **For newer APIs:** If you want to use features added after the installed version, ask for permission and suggest the upgradation.
- **No deprecated APIs:** Don't use anything marked deprecated in the installed version; use the recommended replacement instead.
- **Ask before upgrading:** If a task truly needs a newer version, say so and wait for approval before changing any dependency.
